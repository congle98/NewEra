# Setup Guide

Tài liệu này được tạo hoặc cập nhật theo dự án cụ thể.

## Prerequisites

- Chưa xác định.

## Setup

1. Kiểm tra `environment-manifest.md`.
2. Kiểm tra version các tool.
3. Cài dependency theo lockfile nếu có.
4. Tạo `.env` từ `.env.example` nếu dự án cần.
5. Khởi động service local cần thiết.
6. Chạy smoke test.
