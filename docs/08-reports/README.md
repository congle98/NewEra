# Reports

Thư mục này dành cho report của **project sử dụng NewEra** sau khi project có M/Phase thực tế.

- Dùng `docs/templates/milestone-report.md` cho milestone report.
- Dùng `docs/templates/phase-report.md` cho phase report.
- Dùng `docs/templates/residual-work.md` cho residual ledger.
- Dùng `docs/templates/technical-debt.md` cho technical-debt ledger.

Không tạo report/checkpoint/evidence của chính repository NewEra nếu mục tiêu chỉ là nâng cấp kernel tài liệu và quy trình. Report phải thuộc project scope cụ thể và truy nguyên về ROADMAP của project đó.
