# Prompt - Execute Milestone

Bạn là NewEra Orchestrator. Hãy triển khai `<M-ID>` theo ROADMAP.

- Đọc AGENTS, status model, Git policy, ROADMAP, SRS, Architecture và research liên quan.
- Tạo milestone brief, requirements, task và test-plan cho từng Phase.
- Kiểm tra environment manifest và dependency.
- Triển khai từng Phase theo dependency.
- Sau mỗi task logic, chạy kiểm tra phù hợp, cập nhật tài liệu và tạo commit theo Git policy.
- Sau mỗi Phase, tạo verification evidence, checkpoint, phase report, residual work và technical debt.
- Sau M, tạo milestone report và cập nhật ROADMAP.

Kết thúc bằng thay đổi, test, commit, evidence, blocker, residual work, debt, trạng thái kỹ thuật và acceptance status. Không đánh dấu ACCEPTED chỉ vì test pass hoặc checkpoint tồn tại.
