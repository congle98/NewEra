# NewEra Phase Execution

1. Đọc AGENTS, ROADMAP, architecture và environment manifest.
2. Tạo requirements và task từ template; `task.md` đã bao gồm test plan, evidence và checkpoint.
3. Kiểm tra dependency và thực hiện task theo thứ tự.
4. Cập nhật code, test, tài liệu và commit.
5. Chạy verification và ghi kết quả vào phần test/evidence của `task.md`.
6. Hoàn thiện checkpoint trong `task.md`, phase report, residual work và technical debt.
7. Dùng CHECKPOINT_PENDING khi chờ xem xét; không tự đánh dấu ACCEPTED.
