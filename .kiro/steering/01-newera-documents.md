# NewEra Document Rules

Tài liệu bắt buộc: intake, charter, research, ROADMAP, SRS, Architecture. Tài liệu API, database, security, deployment, migration và UX tạo theo `document-registry.md`.

Mỗi Phase có requirements, task (bao gồm test plan, evidence và checkpoint) và report. Mỗi M có milestone brief, milestone report và residual work.

Cập nhật tài liệu nguồn trước khi triển khai thay đổi ảnh hưởng phạm vi hoặc thiết kế.
